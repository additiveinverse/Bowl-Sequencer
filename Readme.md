# Bowl-Sequencer

An experimental arcade bowling game that generates drum patterns from gameplay.

Bowl-Sequencer started with a simple question:

> What if discovering a groove felt more like playing an arcade game than programming a sequencer?

Instead of editing notes directly, players bowl.

Every frame generates structured data from the outcome of the game. That data can then be interpreted as rhythms, velocity maps, accents, visual artifacts, or future musical structures.

The bowling game comes first.

The music system exists to reward play.

---

## Current Status

Early prototype.

Current focus:

- Arcade bowling gameplay
- Controller support
- Bowling physics
- Capture of gameplay data
- Drum pattern generation from game outcomes

Future ideas include:

- MIDI output
- Hardware drum machine integration
- Artifact export
- Data paintings
- Alternative interpretation engines

---

## Design Goals

- Fun bowling game first
- Music second
- Lightweight and portable
- Raspberry Pi friendly
- Controller friendly
- Deterministic but surprising

---

## Philosophy

Bowling creates artifacts.

Artifacts create music.

Keep these responsibilities separate.
